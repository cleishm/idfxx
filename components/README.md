# Components

All idfxx components, grouped by area. Each area is a directory here, holding its components and a
README that lists them. Each component is published separately on the [ESP Component
Registry](https://components.espressif.com/) as `cleishm/<component>`; see the [main
README](../README.md) for installation and conventions shared by every component.

- **[Core Infrastructure](core/README.md):** idfxx_core, idfxx_hw_support, idfxx_log
- **[System Services](system/README.md):** idfxx_console, idfxx_crypto, idfxx_event,
  idfxx_event_group, idfxx_queue, idfxx_sleep, idfxx_task, idfxx_timer
- **[Networking](network/README.md):** idfxx_net, idfxx_netif, idfxx_wifi
- **[Radio](radio/README.md):** idfxx_radio, idfxx_radio_sx126x
- **[Peripherals](peripherals/README.md):** idfxx_gpio, idfxx_i2c, idfxx_spi, idfxx_onewire,
  idfxx_button, idfxx_rotary_encoder, idfxx_pwm, idfxx_adc
- **[Storage](storage/README.md):** idfxx_nvs, idfxx_ota, idfxx_partition, idfxx_sdcard, idfxx_fatfs
- **[Displays](displays/README.md):** idfxx_panel_io, idfxx_lcd, idfxx_lcd_ili9341,
  idfxx_lcd_ssd1306, idfxx_lcd_image, idfxx_lcd_touch, idfxx_lcd_touch_stmpe610, idfxx_epaper,
  idfxx_epaper_ssd1680, idfxx_epaper_uc8179, idfxx_epaper_el133uf1, idfxx_epaper_image
- **[Graphics](graphics/README.md):** idfxx_gfx, idfxx_font, idfxx_font_spleen, idfxx_font_inter,
  idfxx_image, idfxx_jpeg
- **[Sensors](sensors/README.md):** idfxx_dht, idfxx_ds18x20
- **[Real-Time Clocks](rtc/README.md):** idfxx_rtc, idfxx_rtc_pcf8563
- **[Application Protocols](protocols/README.md):** idfxx_http, idfxx_http_client,
  idfxx_http_server, idfxx_https_server
