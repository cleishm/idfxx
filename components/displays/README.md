# Displays

LCD and e-paper panels, the panel I/O they are connected through, touch controllers, and decoded
images shown on panels. See the [component catalog](../README.md) for every area.

| Component | Description | Documentation |
|-----------|-------------|---------------|
| [idfxx_panel_io](idfxx_panel_io/README.md) | Panel I/O interface for SPI- and I2C-connected displays | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__panel__io.html) |
| [idfxx_lcd](idfxx_lcd/README.md) | LCD panel interface, color types, and framebuffers | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd.html) |
| [idfxx_lcd_ili9341](idfxx_lcd_ili9341/README.md) | ILI9341 LCD controller driver (240x320) | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd.html) |
| [idfxx_lcd_ssd1306](idfxx_lcd_ssd1306/README.md) | SSD1306 monochrome OLED panel driver (128x64 / 128x32) | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd.html) |
| [idfxx_lcd_image](idfxx_lcd_image/README.md) | Decoded images on RGB565 LCD panels and surfaces, placed, sized and oriented on the screen | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd__image.html) |
| [idfxx_lcd_touch](idfxx_lcd_touch/README.md) | LCD touch controller interface | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd__touch.html) |
| [idfxx_lcd_touch_stmpe610](idfxx_lcd_touch_stmpe610/README.md) | STMPE610 resistive touch controller driver | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__lcd__touch.html) |
| [idfxx_epaper](idfxx_epaper/README.md) | Abstract ePaper panel interface with mono, 4-level grayscale, and six-color framebuffers | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__epaper.html) |
| [idfxx_epaper_ssd1680](idfxx_epaper_ssd1680/README.md) | SSD1680 ePaper panel driver (up to 176x296, e.g. 2.13" 122x250) | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__epaper.html) |
| [idfxx_epaper_uc8179](idfxx_epaper_uc8179/README.md) | UC8179 ePaper panel driver (up to 800x600, e.g. 7.5" 800x480) | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__epaper.html) |
| [idfxx_epaper_el133uf1](idfxx_epaper_el133uf1/README.md) | EL133UF1 ePaper panel driver (E Ink 13.3" 1200x1600 Spectra 6 six-color glass, e.g. Seeed T133A01 module in the reTerminal E1004) | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__epaper.html) |
| [idfxx_epaper_image](idfxx_epaper_image/README.md) | Decoded images on e-paper panels and surfaces, in a panel's measured colors, placed, sized and oriented on the screen | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__epaper__image.html) |
