# Graphics

Drawing primitives, bitmap fonts, pixel images, and JPEG decoding. See the [component
catalog](../README.md) for every area.

| Component | Description | Documentation |
|-----------|-------------|---------------|
| [idfxx_gfx](idfxx_gfx/README.md) | Drawing primitives for pixel surfaces: shapes, lines, 1-bit bitmaps, and bitmap-font text | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__gfx.html) |
| [idfxx_font](idfxx_font/README.md) | Bitmap font models (fixed-cell and proportional) and text metrics | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__font.html) |
| [idfxx_font_spleen](idfxx_font_spleen/README.md) | The Spleen bitmap fonts (5x8 and 8x16) as idfxx font data | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__font__spleen.html) |
| [idfxx_font_inter](idfxx_font_inter/README.md) | The Inter typeface (Regular and Medium, 16-48 px) as idfxx proportional font data | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__font__inter.html) |
| [idfxx_image](idfxx_image/README.md) | Pixel image views, owning buffers, EXIF orientation transforms, and placing images on a screen | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__image.html) |
| [idfxx_jpeg](idfxx_jpeg/README.md) | JPEG decoding into RGB888 images, with output scaling and EXIF orientation | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__jpeg.html) |
