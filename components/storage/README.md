# Storage

Non-volatile storage, flash partitions, OTA updates, SD cards, and FAT filesystems. See the
[component catalog](../README.md) for every area.

| Component | Description | Documentation |
|-----------|-------------|---------------|
| [idfxx_nvs](idfxx_nvs/README.md) | Non-Volatile Storage (NVS) wrapper | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__nvs.html) |
| [idfxx_ota](idfxx_ota/README.md) | OTA firmware update session management with rollback support | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__ota.html) |
| [idfxx_partition](idfxx_partition/README.md) | Flash partition discovery, reading, writing, and memory mapping | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__partition.html) |
| [idfxx_sdcard](idfxx_sdcard/README.md) | SD and MMC/eMMC memory cards over SPI or SDMMC, with raw sector access | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__sdcard.html) |
| [idfxx_fatfs](idfxx_fatfs/README.md) | FAT filesystems on SD cards and flash partitions, used through standard file I/O | [API Docs](https://cleishm.github.io/idfxx/group__idfxx__fatfs.html) |
